# OpenChair
An accessibility focused app built to aid wheelchair users.

# Tools To Use
Frontend: React + TypeScript + Tailwind
Backend: Node.js + Express + TypeScript
Database: PostgreSQL
ORM: Prisma
API Testing: Postman
Version Control: Git + GitHub
Deployment: Render/Railway first, AWS later
DevOps Later: Docker
