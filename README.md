# OpenChair
An accessibility focused app built to aid wheelchair users.

# Tools To Use
- Frontend: React + TypeScript + Tailwind
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- API Testing: Postman
- Version Control: Git + GitHub
- Deployment: Render/Railway first, AWS later
- DevOps Later: Docker

# Setup
Before starting development, contributors should ensure they have 
- Install Node.js LTS
- Install PostgreSQL
- Install Postman
- Install the following VSCode Extensions (if on vscode)
	- ESLint
	- Prettier
	- Code formatter
	- Prisma
	- Tailwind CSS IntelliSense
	- PostgreSQL or SQLTools
- Install TypeScript within the program 'npm install -D typescript'

These tools will be used later in the development process so we will install them later
- Docker
- AWS CLI
- Next.js
- React Native
- Java Spring Boot
- MongoDB
- Kubernetes
